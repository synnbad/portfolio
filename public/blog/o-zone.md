`O-Zone` is an AWS AI Maker Hackathon project focused on air-quality decisions.

Environmental data needs a clear next step for users. This repo combines real-time data, pollutant calculations, API design, and AI-assisted recommendations in one workflow.

## What I Focused On

- connecting live environmental data to a user-facing flow
- building API-backed calculations
- using cloud and AI as support for the core decision flow
- making the output easier to understand than a raw data feed

## What This Project Shows

This is my strongest practical AI/cloud example. It connects data, APIs, and guidance around real user decisions.
